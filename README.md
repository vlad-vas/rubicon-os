# Rubicon OS

AI-powered management platform for a computer club.

## About

Rubicon OS is a full-stack system for managing a computer club:
- bookings
- clients
- gaming sessions
- PCs and PlayStation
- tariffs and payments
- staff and permissions
- notifications
- AI assistant
- automation
- analytics and reports

## AI Engineering

The project is being developed as a practical AI Engineering project.

Planned AI capabilities:
- customer communication
- booking automation
- availability search
- booking creation
- session and extension assistance
- human handoff
- tool calling
- business rules
- AI action logging
- permission control

## Tech Stack
